# Allan Baban — Portfolio

Personlig portfolio för Allan Baban, byggingenjörsstudent med inriktning hållbart byggande.

Live: https://fikonagency.github.io/Allan-Baban/

## Stack
Ren HTML / CSS / JS. Scrollanimationer via IntersectionObserver. Inga byggsteg — sidan serveras direkt från GitHub Pages.

## Lokalt
Öppna `index.html` direkt i webbläsaren, eller kör en lokal server:
```
python3 -m http.server 8000
```
